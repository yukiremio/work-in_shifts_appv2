# シフト作成アプリ (work_in_shifts_app)

アルバイトや社員のシフト希望を一目で確認し、シフト調整の連絡を最小限に抑えるためのシフト管理システムです。

## アプリケーションの概要
- **ユーザーゴール**: シフト作成者が、希望シフトを一目で確認し、必要な場合だけシフト調整の連絡を行うだけで済むようにする。
- **ビジネスゴール**: シフト作成の負担を軽減し、シフト調整のミスをなくす。
- **今回の開発範囲**: ログイン、週ごとのシフト希望日の入力、調整必要箇所は赤字にする。

## 画面・機能の説明
1. **ログイン画面**
   - IDとパスワードを入力してログインする画面。ログイン失敗時はエラーメッセージを表示する。
2. **トップページ**
   - ログイン後に表示されるメニュー画面。各画面への遷移（シフト一覧画面、シフト登録画面、自分のシフト、従業員一覧画面、従業員登録画面）およびログアウトが可能。
3. **シフト一覧画面**
   - 登録されているシフトを一覧で表示する画面。一覧表示、検索が可能。
4. **シフト登録画面**
   - 希望シフトを入力、登録、申請する画面。
5. **シフト編集画面**
   - 申請済みのシフトを編集する画面。シフトの変更、削除が可能。
6. **自分のシフト画面**
   - ログイン中の従業員のシフトを表示する画面。
7. **従業員一覧画面**
   - 登録されている従業員を一覧表示する画面。
8. **従業員登録画面**
   - 新しい従業員を登録する画面。

## 主な使用技術 (技術スタック)
- **バックエンド**: Java 21, Spring Boot 3.x, Spring Data JPA, Lombok
- **フロントエンド**: React (予定)
- **データベース**: H2 Database (開発環境用メモリ駆動) / MySQL (本番想定)
- **ビルドツール**: Maven

## データ要件 (主要エンティティ)
- **Employee (従業員)**
  - `employee_id` (従業員ID / 主キー)
  - `name` (従業員名)
  - `email` (メールアドレス)
  - `login_id` (ログイン用ID)
  - `password` (ログイン用パスワード)

## API設計 (実装済みエンドポイント)
- `POST /api/login` : ログイン用API。ログインIDとパスワードを受け取り、認証結果を返す。

## ローカル環境での起動方法
### 必要環境
- Java 21
- IntelliJ IDEA 
- Maven

### インストール・起動手順
1. リポジトリをクローンまたはフォルダを開く。
2. `src/main/resources/application.properties` にH2データベースの設定が記述されていることを確認する。
3. IntelliJ IDEA で `WorkInShiftsAppV2Application.java` を開き、緑色の再生マーク（▶）をクリックして起動する。
